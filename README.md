# TaskFlow – Task Manager App

TaskFlow is a simple and user-friendly Android task management application built with **Kotlin and Jetpack Compose**. It helps users create, manage, and track their daily tasks while keeping track of their overall progress.

## Features

- Create new tasks with relevant details.
- Update task progress and track completion.
- Automatically organize today's tasks.
- Track upcoming tasks.
- Automatically identify overdue tasks.
- Edit and delete existing tasks.
- Manage all tasks in one place.

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- MVVM Architecture
- Kotlin Coroutines & Flow
